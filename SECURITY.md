# Reporting a security issue

Use GitHub's private vulnerability reporting for this repository when it is available. If it is unavailable, open an issue requesting a private contact channel and include only a brief description of the affected component.

Use synthetic data in reproductions. Remove plan files, full Windows paths, credentials, recovery keys, device identifiers, and any personal data from public reports. Describe the affected revision, steps to reproduce, and observed effect. Keep any proof of concept that can write disks confined to disposable VM images.
